## 2. Подмножества и клавиатуры

| Подмножество | ID | Клавиатура |
|---|---|---|
| `baseline` | 001–075 | во всех трёх сессиях одна и та же: код 0 (Lenovo) |

## 3. Имена файлов

`UUUSKT.txt` — 6 цифр **[Readme]**:

| позиция | 1–3 | 4 | 5 | 6 |
|---|---|---|---|---|
| смысл | ID пользователя | сессия 0–2 | клавиатура 0–3 | задача 0–1 |

Пример: `123121.txt` = пользователь 123, сессия 1, клавиатура 2 (Microsoft), задача 1.

Клавиатура лежит в `UB_keystroke_dataset/s<сессия>/<baseline|rotation>/`, мышь — **плоско** в
`UB_mouse_and_events_dataset/`. Имена совпадают один к одному: 888 файлов клавиатуры ↔ 888 файлов мыши **[замер]**.

## 4. Клавиатура: формат строки

```
LMenu KeyDown 63578429757751
Tab KeyDown 63578429757861
LMenu KeyUp 63578429757970
```

`<клавиша> <KeyDown|KeyUp> <время, мс>` через пробел **[Readme]**.

- **Время** — миллисекунды от 01.01.0001 (отсчёт .NET `DateTime`): `63578429757751` → 21.09.2015 **[замер]**.
  Абсолютное значение не нужно, нужны разности.
- **⚠ Шаг таймера ≈ 15,6 мс.** Самые частые разности соседних событий: 78, 94, 109, 62, 47, 31, 125, 16, 0, 15 —
  все кратны 15,625 мс (системный таймер Windows, 64 Гц) **[замер]**. В CMU точность доли миллисекунды.
  Следствия: значения дискретные, бывают **нули**, у признака с малым разбросом отклонение может выйти 0.
- Строки идут строго по времени, битых строк нет **[замер]**.

## 5. Мышь: формат

Описания в архиве **нет** — всё ниже **[замер]**.

Начало файла — служебная шапка (`License Stuff`, `Initialised at`, `Computer Name`, `System User Name`, `IP Address`…).
Там **имя пользователя Windows и IP лаборатории** — данные не коммитить, шапку пропускать.

Строки событий:

```
635784297580483748 | 9/21/2015 10:55:58 AM | Mouse Coordinates | 611,676
635784297650839872 | 9/21/2015 10:56:05 AM | Left | Click
635784297580171748 | 9/21/2015 10:55:58 AM | Window Activated | C:\...\iexplore.exe | <заголовок окна>
```

`<тики> | <локальное время> | <тип> | <данные…>`, разделитель ` | `.

- **Тики** — 100 нс от 01.01.0001 (.NET `DateTime.Ticks`).
- **⚠ Часы общие с клавиатурой:** `мс_клавиатуры × 10 000 ≈ тики_мыши`. На `001000` первая клавиша и первое
  событие мыши расходятся на 0,015 с. Клавиатуру и мышь можно склеить в один поток событий.

| тип | сколько | данные |
|---|---|---|
| `Mouse Coordinates` | 5 457 238 | `x,y` в пикселях, все строки разбираются |
| `Left` / `Right` | 33 516 / 3 596 | всегда `Click` — **нет** нажатия/отпускания по отдельности, **нет** колеса и перетаскивания |
| `Window Activated` | 34 084 | путь к exe, заголовок окна |
| служебные | ~2,9 тыс. | `Closing Down`, `Logging Session Complete`, `Switch Task…`, `…Exception`, `Sending Feedback<цифры>` — пропускать |

Координаты пишутся с тем же шагом ≈ 15,6 мс (медиана), есть дубли с разностью 0.

## 6. Чем отличается от CMU

| | CMU | Buffalo |
|---|---|---|
| текст | один пароль `.tie5Roanl` | длинный фиксированный + свободный |
| что в файле | готовые признаки H / DD / UD, секунды | сырые события, признаки считать самим |
| точность времени | < 1 мс | шаг 15,6 мс |
| сессии | 8, в один-два дня | 3, через ~28 дней |
| смена клавиатуры | нет | rotation, 73 человека |
| мышь | нет | есть, те же часы |

   | | медиана | < Δ/4 = 3,9 мс | < Δ = 15,6 мс | ровно 0 |
   |---|---|---|---|---|
   | удержание | 8,3 мс | 7,3 % | **92,4 %** | 6 из 3271 |
   | UD | 35,9 мс | 0,6 % | 21,1 % | 1 из 4998 |

   - **нижняя граница разброса** из теории квантования: ошибка округления равномерна на ±Δ/2 ⇒ её ср. абс.
     отклонение Δ/4 ≈ 3,9 мс, дисперсия Δ²/12 ≈ 20,3 мс² (поправка Шеппарда). Разброс меньше шума измерения —
     артефакт. Scaled Manhattan: `отклонение = max(MAD, Δ/4)`; GMM: `σ² ≥ Δ²/12` (дефолтный `reg_covar=1e-6`
     в sklearn тут бесполезен). Δ — параметр источника: для CMU ≈ 0 ⇒ результаты ML-02/03 не меняются;
   - текущая маска `deviations != 0` в SM на Buffalo молча выкинула бы признак у человека — граница лучше;
     маска остаётся для признаков, постоянных у всех (correctionRate в CMU);
   - **удержания на Buffalo грубые:** у 92 % разброс меньше одного шага таймера — значения прыгают между
     соседними делениями. Ожидать, что различают людей в основном UD. Абляция в таблицу: только удержания /
     только UD / оба. В браузере таймер точнее ⇒ для сервиса оценка по удержаниям пессимистична — ограничение;
   - дизеринг (добавить шум ±Δ/2) отвергнут: случайность в результатах, граница детерминирована и обоснована.
7. ~~**Мышь**~~ **Решено 03.11.2026.** Замер по 888 файлам:
   - координаты пишутся **только при движении** (шаг 15,6 мс, разрыв = мышь стоит); 13,2 % точек — повтор
     предыдущей; экран в основном 1920×1080, но x от −920 до 3217 — бывает второй монитор;
   - на файл (медиана): 6500 точек, **40 кликов**, 19 мин; от остановки до клика медиана 94 мс (p90 312);
   - сегментов при паузе > 500 мс — 46 на файл, из них ~38 заканчиваются кликом;
   - **88 файлов (все — задача 1; 65 человек; 50 из них в s0) без координат** — клики и окна записаны,
     движения нет (сбой логгера мыши). Мышь в s0 задаче 1 есть не у всех.

   Решения:
   - **объём сейчас:** загрузчик v1 — клавиатура полностью; мышь — только разбор в сырые массивы
     `(t, x, y)` и `(t, кнопка)` на **общих часах** с клавиатурой. Признаки мыши — на этапе DM-05;
   - **единица поведения:** действие = движение между паузами > 500 мс; типы MM (без клика) и PC (с кликом ≤ 500 мс
     после остановки). DD (перетаскивание) невозможно — нет нажатия/отпускания кнопки;
   - **признаки действия** (Ahmed & Traore 2007; Zheng и др. 2011; Antal & Egyed-Zsigmond 2019 — Balabit):
     длительность, длина пути, прямолинейность, скорость/ускорение, кривизна и углы, направление (8 секторов),
     пауза перед кликом. Только относительные величины (dx, dy) — не абсолютные координаты (мониторы разные);
   - **очистка:** склеивать точки с одинаковым временем и повторы (иначе dt = 0 ⇒ бесконечная скорость);
     короткие действия (< 5 точек) отбрасывать; скорость сглаживать — тот же шаг 15,6 мс;
   - **слияние с клавиатурой — на уровне оценок:** окно клавиатуры и действие мыши дают каждый своё приращение
     LLR в **один** CUSUM по времени. Нет мыши — просто нет приращений (88 пустых файлов не ломают поток).
     Мышь редкая (~2 клика/мин против ~90 нажатий), её роль — покрыть время, когда человек не печатает.
